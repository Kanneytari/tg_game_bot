# Контекст проекта для новых чатов

Репозиторий `Kanneytari/tg_game_bot` — основной источник истины по проекту текстовой RPG для Telegram.

## Как работать с репозиторием

- Актуальные принятые решения находятся в `docs/`.
- Начинать чтение с `README.md`, затем с `docs/00-concept.md` и `docs/roadmap.md`.
- Перед изменением существующего файла всегда сначала получать его актуальную версию.
- Не дублировать один и тот же факт в нескольких местах без необходимости.
- Документация описывает правила и принятый дизайн. После появления игровых данных конкретный баланс — HP, цены, веса встреч и другие часто меняемые числа — должен храниться в данных, а не одновременно в Markdown.
- Техническая реализация и стек не фиксируются заранее: сначала стабилизируется дизайн MVP.

## Текущий фокус

Ближайшая цель — спроектировать вертикальный срез MVP: старт в Оазисе, первое прохождение маршрута до Атланты, бой, добыча, экономика, развитие персонажа, смерть/рекреация и последующее открытие более безопасного перемещения между уже освоенными городами.

Актуальный порядок дальнейшей работы находится в `docs/roadmap.md`.
