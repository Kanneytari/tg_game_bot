# Боевая система

Бой должен быть достаточно простым для текстового Telegram-интерфейса, но оставлять пространство для тактики.

## Общая временная шкала

Рабочая идея — действия игрока и противников располагаются на единой временной шкале.

Каждое действие имеет стоимость в очках действия / времени: например, перемещение, выстрел, перезарядка или использование предмета.

Действие с более ранним моментом завершения происходит раньше. При одинаковом времени завершения базовый приоритет получает игрок.

Пример:

- действие NPC стоимостью 3 → завершение на t=3;
- действие игрока стоимостью 5 → завершение на t=5;
- второе действие NPC стоимостью 3 → завершение на t=6;
- второе действие игрока стоимостью 5 → завершение на t=10.

Точная формула очков действия, инициативы и скорости пока не зафиксирована и должна быть проверена прототипом.

Подготовка к бою, оружие, состояние персонажа и выбранная тактика должны быть важнее многократного нажатия кнопки «Атаковать».
