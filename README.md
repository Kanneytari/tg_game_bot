## Как устроена документация

`docs/00-concept.md` — короткий документ верхнего уровня. Подробности живут в тематических файлах.

Файлы в разделе «Предметы» описывают разные стороны одной общей модели и не вложены друг в друга: оружие, экипировка, расходники и износ — отдельные темы.

Основные документы описывают только принятые правила. Системы, которые точно входят в направление проекта, но ещё не спроектированы, хранятся в roadmap.
