## Как устроена документация

`docs/00-concept.md` — короткий документ верхнего уровня. Подробности живут в тематических файлах.

`docs/data-model.md` фиксирует структуру игровых сущностей и их связи, но не техническую реализацию.

Основные документы описывают принятые правила. Пока код и отдельные файлы игровых данных не существуют, черновой контент и баланс могут храниться в документации как единственный источник истины. После перехода к реализации конкретные HP, цены, веса встреч и другие изменяемые значения должны жить только в игровых данных и не дублироваться в Markdown.
