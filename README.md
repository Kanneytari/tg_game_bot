# TG Game Bot — дизайн-документ

Здесь хранится актуальная концепция текстовой RPG для Telegram. Обсуждаем идеи в ChatGPT, а принятые решения фиксируем в этих Markdown-файлах.

- [Игровой цикл](docs/gameplay.md) — что игрок делает в первые часы и как игра меняется дальше.

## Как устроена документация

`docs/00-concept.md` — короткий документ верхнего уровня. Подробности живут в отдельных файлах и связаны обычными Markdown-ссылками.

Новые механики не добавляются в документы «на всякий случай». Сначала обсуждаем, зачем они нужны игре, затем фиксируем принятое решение.
