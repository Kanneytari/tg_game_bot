## Принцип работы

Обсуждаем идеи в ChatGPT → после принятия фиксируем их в соответствующем Markdown-файле → GitHub хранит актуальную версию и историю изменений.

`00-concept.md` остаётся компактным документом верхнего уровня. Детали выносятся в тематические файлы, чтобы основной концепт не разрастался в энциклопедию.
