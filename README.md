## Принцип работы

Обсуждаем идеи в ChatGPT → после принятия фиксируем их в соответствующем Markdown-файле → GitHub хранит актуальную версию и историю изменений.

`docs/00-concept.md` остаётся компактным документом верхнего уровня. Подробности выносятся в тематические файлы, между которыми используются обычные Markdown-ссылки.
